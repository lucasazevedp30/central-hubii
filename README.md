# Central Hubii

Automação de impressão (descritivos e etiquetas), conferência de despacho, pendências e compra
contínua para lojas que vendem na Shopee pelo Hubii.

- Instalar ou atualizar: baixe o `hubii-central-x.y.z.zip` mais recente em **Releases** e, no painel
  da Central, use *Ajuda e backup → Instalar de um arquivo .zip* (sem extrair).
- Depois da 2.16.1, o próprio painel avisa quando há versão nova.

O código fica em `hubii-pacote/`.
